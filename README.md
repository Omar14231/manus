# Manus Game Experiments

## Voxel World

An original browser voxel sandbox built with React, TypeScript, Vite, and Babylon.js in Manus WebDev.

The game is inspired by the block-building genre but does not copy Minecraft branding, assets, characters, or code.

The Roblox graphics experiment is in [`RTXLikeGraphics.client.lua`](./RTXLikeGraphics.client.lua).

The playable WebDev project lives in the Manus-managed `voxel-world` project and will be mirrored here after visual verification.
